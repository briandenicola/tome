# Tome v0.7.0

The first release of the [briandenicola/tome](https://github.com/briandenicola/tome) fork of [masonfox/tome](https://github.com/masonfox/tome). The image is `ghcr.io/briandenicola/tome`.

## Before you upgrade

- **Back up `tome.db`.** Migration `0023` rebuilds the `books` table so a book can exist without a Calibre id. Tome backs up the database before migrating, but keep your own copy too.
- **Everyone signs in again once.** The old sign-in cookie could be forged and no longer counts.
- **Behind a reverse proxy, send `X-Forwarded-For`.** Without it, every visitor shares one limit on wrong passwords.

## What's new

- **A signed-in API.** Every `/api` route needs a sign-in or an API token. Make tokens under **Settings → API tokens**: Read tokens can only read; Write tokens can change things. Sign-in sessions are signed and last 30 days, and five wrong passwords means a one-minute wait.
- **Calibre is optional.** Add books by hand under **Library → Add book**, with a cover upload or URL; **Look up** fills the form from the ISBN (Open Library, only when clicked). Calibre books keep syncing as before.
- **Covers in backups.** Backups now include the covers of books added by hand, and a restore puts them back.
- **Progress from your reading apps.** Set the Audiobookshelf or Grimmory variables and Tome logs your progress from them every 15 minutes, Kobo progress included. See **Settings → Reading apps** and `docs/DEPLOYMENT.md`.
- **A feed for the life store.** `GET /api/lifestore/records`, read with a Read token.

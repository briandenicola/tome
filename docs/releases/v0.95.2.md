# Tome v0.95.2

## What's new

- **Look back on a year from an AI assistant.** Tome's MCP server has two new read-only tools. A Read API token can use both.
  - `books_read` lists the books you finished in a year, with dates, days taken, rating, pages, format and tags.
  - `year_review` sums up the year, as the Year in review page does.
  
  Both default to this year. See **AI agents (MCP)** in `docs/DEPLOYMENT.md`. If your client was already connected, reconnect it so it picks up the new tools.
